# Context Wizard plugin

This directory is the Claude Code plugin of [Context Wizard](https://github.com/Anthony14FR/Context-Wizard). It contains the manifest, the hooks and the launchers. The `wizard` binary is not stored here: it is downloaded on first use for your platform and verified against a pinned checksum.

Install it from the repository marketplace:

```sh
claude plugin marketplace add Anthony14FR/Context-Wizard
claude plugin install context-wizard@context-wizard
```

See the [project README](https://github.com/Anthony14FR/Context-Wizard#readme) for what it does and how it works.
